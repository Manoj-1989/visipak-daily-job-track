Set Up This Device

Enter the stage supervisor's phone number and this device will automatically be set up for their stage. It will then only be able to add or edit job cards for that stage — entries from other stages will show read-only. You can change this anytime from the header.

Manage Supervisors

Add each supervisor's phone number and the stage(s) they should have access to. When they enter their number on a device during setup, that device locks to just those stages. Re-adding (or clicking Edit on) a number that's already listed updates their name/stages. Give a shift in-charge "All stages" for full access.
