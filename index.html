Log In to This Device

Enter your phone number to log in. This device will automatically be set up for your assigned stage(s), and job cards you add or edit will be tagged with your name. It'll only be able to touch those stages — entries from other stages show read-only. Sharing this device with someone else? Log out when you're done so the next person logs in with their own number.

Manage Users

Add each user's phone number and the stage(s) they should have access to. When they enter their number on a device during setup, that device locks to just those stages. Re-adding (or clicking Edit on) a number that's already listed updates their details. Give someone like a shift in-charge "All stages" so they can add and edit job cards anywhere — that alone doesn't give them Manage Users or Activity Log; only the admin phone number gets those.
